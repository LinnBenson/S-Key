# 内置词库管理与编译

默认每类按“S Key 基础词库、本地高优先级词库”顺序显示。五笔仅包含 86，共 136916 条；拼音 65125 条；英语 25000 条。三个高优先级模板均为空。默认来源为 Rime 五笔、Rime 简体拼音及 FrequencyWords/SCOWL 英文；来源、许可和哈希见 third_party/open_dictionaries/README.md。

完整编码命中时高优先级词条在前，同编码按文件顺序。普通五笔与拼音按词频降序、原始顺序排列；英文补全按词频降序、字母顺序排列。前缀不强制置顶。重复文字和编码合并，不改普通词频。

所有拼音类型词库均为混输来源，包括基础、补充和高优先级词库；修改后需重新编译应用。三个基础词库和三个 _high.tsv 词库均禁止删除和重命名，允许编辑、导出与编译。混输保持五笔精确匹配、拼音候选、五笔前缀补全的顺序。单字母索引从当前基础拼音单字音节派生，混输使用 S Key 自身的查询和合并算法。

输入方式只有五笔和拼音。选择五笔时显示“四码自动上屏”和“五笔拼音混输入”开关；后者映射到引擎 MIXED 模式。切换到拼音后保留五笔偏好，工具面板也只循环五笔和拼音。


数据位于 noBackupFilesDir/builtin-dictionaries-v3/：defaults.db 为默认目录，files.db 为草稿目录，runtime.db 为默认索引。original-*.txt、edit-*.txt 保存原文，compiled-*.db 为不可变快照，active 原子发布当前快照。恢复默认只替换草稿，需编译应用。

编辑、导入和分段保存首先修改草稿；编译成功才生效，失败保留原生效版本。编译流式解析并合并同类型同文字同编码记录，格式错误报告文件名和行号。查询和候选点击、分页通过版本检查避免旧结果。运行时按需读取 SQLite，不载入整库对象；schema user_version 为 3，短前缀预建排名表。

导入和保存必须通过完整源文件校验：UTF-8、每行最多 8192 字符、每文件最多 64 MiB、合法编码和整数词频；编译入口再次限制文件大小并逐条验证。无效控制字符、小数词频（包括旧版特殊例外）及溢出词频被拒绝。编辑拒绝无效 Unicode，避免编码替换后悄悄改变词条。空高优先级词库合法；新建空模板可以暂存，普通空库不能编译。

构建由 Gradle 调用 scripts/build_dictionary_catalog.py 并校验源文件哈希。tests/test_dictionary_catalog.py 校验全量词频、排序、前缀和查询计划。BuiltinDictionaryTest 验证手机完整编译、替换、空模板、优先级和错误恢复；DictionaryEngineDeviceTest 验证真实设备引擎。

本地导入支持同名覆盖：类型必须一致，完整校验通过后事务更新原记录的源文件路径，保留 ID、顺序及优先级。校验失败保留原草稿和生效快照；成功覆盖标记待编译，并使旧编辑分页版本失效。新建文件仍拒绝重名。


高优先级文件统一为 skey_wubi86_high.tsv、skey_pinyin_high.tsv、skey_english_high.tsv。六个受保护名称由 BuiltinDictionaryFiles 管理。当前词库使用独立存储 builtin-dictionaries-v3，不迁移旧目录；运行时不识别旧文件名别名。

编译成功后在仓库锁外释放进程级旧引擎、SQLite 连接及查询对象，再清理已关闭快照；下次查询仅打开 active 指向的新库。不保留旧词库回退。内置 APK 资源仍留在磁盘用于恢复默认，但不会同时加载进引擎。

正式签名打包由 verify_dictionary_apk.py 检查词库资源白名单、六个源文件、基础源哈希、空高优先级模板以及 catalog/runtime 索引哈希，拒绝多余词库或过期构建资源。emoji_keywords.tsv 是保留的表情关键词功能资源。

混输候选查询为五笔、精确拼音与模糊拼音分别保留有界候选名额，避免共用上限导致模糊音不可达。模糊查询在截取结果前排除相同完整拼音编码，防止精确同音词重复占位；保留各模糊音开关控制。
