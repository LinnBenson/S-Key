# 内置词库管理与编译

偏好设置的“输入与外观”与“本机内容”之间增加“内置词库”栏目。

## 用户行为

- 按五笔、拼音、英文分类直接显示原始文件名（例如 `wubi86.dict.yaml`）。支持新建、导入、重命名、导出、删除文件。
- 打开文件编辑原始文本，保留 YAML 头部、注释、制表符和未编辑行的原始换行。每段最多 120 行，并限制字符数；支持全文搜索定位、上一段/下一段和插入 Tab。编辑器用 Miuix 卡片及主题，固定底栏保存。
- 可导入 `.dict.yaml`、`.tsv`、`.txt`。YAML 仅解析 `...` 后的数据行。五笔和拼音数据格式为 `文字<TAB>编码<TAB>词频`（词频可省略，默认为 0）；英文为 `单词<TAB>词频`。仅解析文本数据，不执行 Rime 配置或脚本。
- 所有编辑首先进入草稿。点击“一键编译并应用”成功后，键盘才使用新版本；编译失败保留原生效版本。
- 恢复默认替换全部内置词库草稿，包括用户创建的词库；仍须编译后应用。界面会先确认。
- 原有中文、英文自定义词库不进入此编译流程，继续即时生效；原有用户内容备份范围不变。
- 五笔编码为 1–4 个小写字母；拼音音节用空格分隔，最多 64 字符；英文为 2–40 个 ASCII 小写字母。英文词频须为正整数，其他词频为非负 Long 整数。

## 数据与发布

`DictionaryRepository` 在应用的 `noBackupFilesDir/builtin-dictionaries/` 保存数据：

| 文件 | 用途 |
| --- | --- |
| `defaults-v4.db` | 从 APK 复制的默认来源目录，恢复默认的依据 |
| `files-v2.db` | 文件目录、原始文件版本指针和待编译状态 |
| `original-*.txt` | 从 APK 按原始字节复制的默认源文件 |
| `edit-*.txt` | 修改或导入的源文件，文件目录事务发布版本 |
| `parsing-*.db` | 编译时解析源文件的临时数据，不参与查询 |
| `runtime-v2.db` | 预先生成的默认只读查询索引 |
| `building-*.db` | 手机端编译中的临时文件，不参与查询 |
| `compiled-*.db` | 完成校验的不可变编译版本 |
| `active` | 通过 AtomicFile 发布的当前版本文件名 |

编译按来源顺序读取原始文件，格式错误报告文件名和行号。合法词条先流式写入临时数据库，再在独立数据库中合并同类型、同文字、同编码的重复行。保留首条普通权重；五笔优先来源仍可提升已有重复项的完整编码候选位置。前缀查询不采用完整编码优先级。新版本校验、同步、重命名完成后才发布指针。旧查询由 `OfflineEngine` 的锁保护，在替换读者后关闭旧数据库。

发布通知通过设置中的版本值使当前候选失效。后台查询和候选点击均检查版本，避免旧候选在切换后被插入。编译与正常查询使用不同的锁；编译不会持有运行时查询锁。

查询使用只读 SQLite 文件及有限页缓存，不在启动时解析全部文本，也不建立整库 Kotlin 对象索引。它不是原有 SKWB 内存映射格式；数据库占用更多磁盘，性能需按设备实测，不能据此宣称所有按键查询都更快。拼音继续复用现有模糊音、音节边界和组词算法，仅把索引读取替换为按需查询。

## 构建与来源

`python3 scripts/build_dictionary_catalog.py` 使用固定源数据生成两个数据库；Gradle 的 `preBuild` 自动执行该任务。输出在 `app/build/generated/dictionaryCatalog/dictionaries/`，不提交生成数据库。

原始五笔 YAML、SKWB、拼音 YAML、英文 TSV 和许可证继续保留。五笔源文件哈希由原有 manifest 校验。扩展词库原有许可范围不因本次技术调整而改变。

默认来源目录版本为 v4，草稿目录保持 v2，查询索引版本为 v2。后续更改随包默认词库时，应同时升级缓存文件版本；用户已编译版本不应被应用升级静默覆盖。

## 验证

- `python3 tests/test_dictionary_catalog.py`：来源计数、数据库完整性、所有五笔精确组及前缀候选顺序对照。
- `BuiltinDictionaryTest`：手机端完整默认编译、源文件增删改、逐字节导出、分段保存与恢复、错误行定位、编译失败保留旧版、拼音及英文结果对照。
- 原有引擎、输入法生命周期、自定义词库和 AI/翻译回归继续适用。

英文默认包含高频库 25,000 词和 ESDB 扩展库 108,051 词，总计 133,051 词。扩展来源、许可和离线重建步骤见 `third_party/english/README.md`。已有草稿及用户编译版本不会被升级覆盖；已有管理草稿可通过恢复默认再编译加载新默认来源。
