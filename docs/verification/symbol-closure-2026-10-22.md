# 可编辑符号闭合规则（2026-10-22）

“内置设置”增加“符号自动闭合”，提供输入符号、闭合符号、光标回移位三列，支持添加、修改和删除。新安装使用原有四条默认规则：双引号、单引号、大括号、中括号，回移均为 1。删除全部规则后保持空列表，不重新生成默认值。

规则仅匹配中英文符号页点击的一个输入字符，不监测宿主输入、不对粘贴内容或字母页输入做序列匹配。输入符号一个 Unicode 码点；闭合内容 1–16 个码点；回移为 0 到插入总字符数。回移按码点换算为 Android 所需的 UTF-16 偏移，避免拆开 emoji 代理对。0 留在末尾；1 从末尾向左移动一个字符。匹配后保留原有返回字母页行为。

保存后即时读取；待确认输入队列捕获按下时的完整规则和回移量，后续规则修改不会重解释已排队的输入。配置保存在私有 `symbol_closure` 偏好设置，尚未纳入用户内容备份。

测试覆盖默认四对的选区替换与光标、AI/翻译原文框、无规则符号原样插入、新增中文规则、修改后即时使用、删除后停止闭合、0 回移及 emoji 回移、持久化、删除全部、重复与越界校验。

结果：Debug 应用与设备测试包构建成功，218 项 JVM 测试通过，6 项设备回归全部通过，隐私静态检查通过。已检查三列设置页实际布局。签名 ARM64 Debug APK 和预览输出到外层 `package/builtin-dictionaries/`。
