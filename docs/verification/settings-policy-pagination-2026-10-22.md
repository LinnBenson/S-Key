# 候选分页、剪贴板保留与设置备份

## 行为

- 候选先读取 40 条；横向滚动接近末尾、展开候选或展开列表滚动时继续取页。五笔四码、拼音单字母和拼音精确词条、英文补全使用 SQL 分页；游标在每次查询结束关闭。自定义词条沿用索引快照，合并过程按需遍历，不生成完整候选副本。更换输入、编辑器或词库版本后，旧页不能回填。
- 已加载候选留到本轮输入结束，保证往回滚动和点选稳定。展开列表复用单元格。短五笔前缀仍沿用现有候选规则；整句拼音搜索保留有限宽度，不枚举全部可能句子。
- 剪贴板默认长期保留。可选择不保存历史或按小时清理。未置顶条数上限独立计算；置顶不自动过期，也不因新记录到来被挤掉。总字符容量仍受限制，置顶最多 1000 条。容量被置顶占满时跳过新增历史，不影响系统粘贴。
- 旧剪贴板记录首次迁移时补充时间戳；重新复制更新时间。定时清理由单个可替换 JobScheduler 任务执行，系统休眠可能延迟；读取历史和再次打开键盘时会补做清理。无永久后台服务、无精确闹钟权限。手动删除仍按原规则清空匹配的系统剪贴板；自动过期不清空系统剪贴板。
- `pinyin_simp.dict.yaml` 不能删除或重命名。界面不提供对应操作，仓库 API 也拒绝；仍可编辑内容并编译。

## 备份范围与还原

格式版本 2 包含原版本 1 的中文/英文自定义词库、常用语、自定义 AI，新增主题及候选字号、四类布局、工具栏、自动闭合规则、中英文两页符号、字母长按符号和内置 AI 提示词。

明确排除 API 密钥、剪贴板、最近表情、会话、内置词库文件和语音模型。配置使用固定白名单，不遍历导出整个 preferences。导入限制字段、层级、数量、字符串长度、类型与数值范围，拒绝未知设置键。旧版只恢复原有四类内容。

选择文件后先读取和验证，显示各类数据前后条数以及设置差异数量。确认前不写入；确认后应用内存中的同一个已校验快照，不重新读取外部文件。配置与内容写入失败时尝试回滚。此流程不宣称跨多个 preferences 文件在设备突然断电时具有数据库事务保证。

## 拼音质量基线

固定例句位于 `app/src/androidTest/assets/pinyin_quality.tsv`，运行 `PinyinQualityCorpusTest`。使用随包真实词库，不读取用户的编译词库。包含 12 个固定例句，以及分段/撤回检查；覆盖多音字、明确分界与不分界、短语、完整长句、简繁词组及上下文预测。

表中第 4 列始终是期望首选；第 6 列仅用于明确记录已知问题的当前首选。测试允许已知基线或目标结果，其他变化失败；已知问题会通过 instrumentation 状态单独报告，不算作质量达标。

目前已知：“中华人民”之后期望“共和国”，当前词库缺少完整词组，退回短上下文后首选为“币”。这是词组覆盖和联想能力的限制。不能将测试通过解释为所有例句都已达到期望质量。

## 设置样式

设置页使用 Miuix 组件。Compose 弹窗共用宽度（最大 600dp、两侧 20dp）、20dp 内边距、14dp 内容间距和 12dp 操作间距。确认操作采用左取消、右主按钮。页面共用横向 20dp、纵向 12dp 留白；设置图标统一跟随界面文字色，避免键盘工具栏自定义色影响设置页可读性。
