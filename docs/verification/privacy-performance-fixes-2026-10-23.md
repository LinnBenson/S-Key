# 密码表情记录与性能修复验证

日期：2026-10-23。基于 1.0.85 / versionCode 92，起始提交 a9137c8。只修改本次指定的表情历史、设置读取和离线语音取消路径，未发布新版本。

## 修改

- 密码字段仍允许输入表情，但不读取/展示最近表情，也不写入使用历史。普通字段提交被拒绝时不记录。
- 最近表情独立保存到应用 noBackupFilesDir/recent-emoji/history.json，保留最多 50 项、去重和最近使用排序。使用 AtomicFile 保存；不再因点击表情重写整个 content.json。
- 从旧 content.json 自动迁移表情：新文件持久化成功后才删除旧字段；迁移中断会重试删除旧字段，避免遗留被淘汰的历史副本。词库、剪贴板、常用语格式和备份格式不变；还原备份继续保留最近表情。
- 表情面板异步读取最近记录；点击后的写入使用有界单线程队列，不在 UI 线程读写磁盘。清空表情/清空全部会更新 generation，旧任务不能写回；服务销毁会排空已接受的写入，回调只弱引用 session，不保留界面。进程被系统直接杀死仍可能中断尚未完成的异步写入，不承诺强制终止时的持久化。
- 设置读取采用一致快照，避免按类别重复解析共享内容（首次旧表情迁移可能额外读取一次）；文件身份/修改时间、保留策略和最近表情变化时失效，剪贴板到期也会刷新。未变化时复用已有列表；获取模型、保存/清除 API 配置以及读取/导出备份不再无条件加载所有内容。
- 离线语音在读取模型前及每个校验分块之间检查取消状态，避免松手或切换输入框后继续完成旧校验。正常识别仍完整校验哈希并新建/释放识别器；没有引入跨会话原生识别器缓存或音频缓存。

## 离线语音测量与选择

使用固定版本的官方模型及公开 0.wav，不使用用户录音；只在隔离测试 APK 中提供这些样本。SHA-256 与项目既有固定值一致。未打开麦克风进行实录。

最终一轮 5 次测量，单位毫秒：

| 阶段 | 五次测量 |
|---|---|
| 模型和 tokens 校验 | 30、12、12、12、12 |
| 原生识别器创建 | 405、354、374、357、371 |
| 新建识别流（毫秒取整） | 0、0、0、0、0 |

这是当前 Android 测试环境的数据，不是所有手机的性能承诺。首次诊断的 126ms 校验项还包含测试样本解包，未将它当作纯哈希成本。

创建识别器是主要成本。考虑到本次优先要求兼容性和避免新问题，没有用长期驻留的识别器换取延迟降低；优化仅针对取消后的无效工作。正常首次启动耗时没有声称显著降低。验证了正常识别结果、全新静音流无上一轮文字、重复语句端点切分与最终 flush。
