# 1.1.2 发布检查 · 2026-10-24

版本：1.1.2（108）。本轮覆盖设置页敏感数据生命周期、输入框隐私标记、翻译密钥传输与空格查词。

## 变更

- 输入框禁止个性化学习时，不采集剪贴板、不记录最近表情，也不触发空格查词。
- 设置页只加载当前页面需要的数据；离开页面或进入后台时清空敏感页面状态，旧加载结果不能回填。未保存的敏感草稿会丢弃。
- Google 翻译及语音自动翻译使用 `X-Goog-Api-Key` 请求头，URL 不再包含密钥。
- 中文候选上屏后优先查询本次提交的二至四字完整词，未命中时读取光标前最多四个 UTF-16 单元，按四字、三字、两字查询连续中文后缀。标点、空格不会被跨越拼接。
- 提交确认的光标回调不会误取消当前查询；真正移动光标会取消。新提交、隐藏键盘、关闭功能都会使旧结果失效。
- 删除不再使用的全量设置内容快照及相关测试代码。

## 验证

- JVM 单元测试：256 项通过。
- Python 构建与资源测试：10 项通过。
- 静态隐私检查和 Git 差异空白检查通过。
- root BlueStacks 隔离测试包：隐私与设置回归 21 项通过，查词与中文候选回归 12 项通过。
- arm64-v8a、x86_64、universal 正式包：发布签名、版本与词库资源核验通过。

设备用例覆盖设置页切换、后台释放、旧加载回填、翻译请求头、完整词优先、分开输入的后缀匹配、未命中、标点边界、旧查询取消、8 秒恢复，以及重复关闭后的数据库连接和工作线程释放。

## 验证边界

设备回归使用独立包名，不覆盖模拟器中的正式应用或用户内容。未使用真实 API 密钥进行在线请求，也未进行长时间整机堆分析。释放引用和关闭资源不等于对托管堆内存进行物理覆写；输入片段不写入历史、日志或网络请求。
