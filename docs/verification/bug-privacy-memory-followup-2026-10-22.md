## 本轮修复

快捷粘贴此前只在打开键盘时检查复制时间，键盘一直打开时可能持续显示超过五分钟的内容。本轮加入单个到期回调，过期即清除状态并刷新工具栏；点击前再次检查，防止主线程繁忙、回调尚未执行时插入过期文本。键盘收起取消回调，Service 销毁清空 Handler，回调本身不捕获复制文本。

保持下次打开仅显示一次、打开期间新复制留待下次、输入即关闭的规则。历史记录的保留策略独立生效。更新设备测试的合成时间戳，使其代表实际复制时间，新增持续显示到期和延迟点击两条回归。

## 隐私与资源检查

- 清单禁止明文网络和系统备份；输入路径不直接调用网络。AI/翻译请求由显式操作触发，禁用重定向，设置超时、响应大小上限和取消检查。
- API 配置继续使用 AndroidKeyStore/AES-GCM；设置备份按白名单写入，不导出 API 密钥。
- 敏感剪贴板标记被过滤；密码框禁用候选和自动剪贴板捕获。测试检查普通输入/助手草稿不写入本地文件或偏好设置。
- 候选按页读取；剪贴板写入队列限制任务数和文本总量；取消任务、收起面板及销毁服务释放相应引用。字体、词库存在进程内共享缓存，因此进程驻留内存不应理解为每次收起都会归零。
- 临时词库/模型文件使用明确名称范围清理，不扫描删除用户其他文件。
