# S Key 1.0.30 隐私与内存审计

日期：2026-10-18（Asia/Singapore）。覆盖当前新增 AI 功能及既有输入、内容管理、翻译、语音、主题相关代码和回归测试。不是无漏洞或全设备保证。

## 已修正

- 取消 AI 请求时同步释放语音指令会话；内容版本失效的回调会释放对应旧会话，避免录音/网络任务完成后仍保留会话引用。
- AI 清空操作重建面板，避免新增控件引用已清除但界面仍留在旧状态。
- 修正声波清理语句缩进，静态检查不再报错。
- 从最终合并清单移除 EmojiCompat 自动初始化元数据，保留其他 AndroidX 初始化器。APK 中存在该运行时组件，lint 对显式 provider 声明的 MissingClass 为误报，已仅对该节点定向忽略；最终清单确认没有 EmojiCompatInitializer。

## 隐私与日志

生产 Java/Kotlin 源码静态搜索未发现 Log、println、printStackTrace、网络日志拦截器或分析/崩溃上报 SDK 调用。系统日志中的两个人工隐私标记及两个测试密钥标记均为零命中；没有导出实际日志全文或用户密钥。此结果只覆盖本次测试路径，不能证明系统及所有第三方运行时永远不记录数据。

API 配置由 Android Keystore + AES-GCM 加密；清单禁用备份、设备迁移数据以及明文 HTTP。请求禁止自动重定向，并限制响应大小。普通输入与离线语音不走应用网络接口；翻译、AI 生成、模型列表、AI 语音为显式网络功能，用户配置的 HTTPS 地址可以是其他服务商。离线模型下载仍通过用户点击后打开浏览器访问 GitHub。

剪贴板、常用语、词库和手动保存的自定义提示词是应用私有 no_backup 目录中的本地明文，不是加密内容库。AI 原文、结果和补充要求不写入内容库；历史最多 8 版，退出输入/模式后清空引用。录音在内存中，60 秒上限，结束清零 PCM 缓冲并释放 AudioRecord；不可保证 JVM 字符串在清除引用后立即被物理擦除。

## 内存观察

60 次 AI/翻译面板开关循环，包含每次填入 8 版人工结果及补充要求：

| 阶段 | PSS KiB | Java 已用字节 | Native 已分配字节 | 旧结果视图存活数 |
|---|---:|---:|---:|---:|
| 起始 | 137414 | 24617456 | 10642720 | 0 |
| 第 10 次 | 137014 | 21996000 | 11292528 | 7 |
| 第 30 次 | 142074 | 22799032 | 12309456 | 7 |
| 第 60 次 | 143740 | 23261384 | 12362256 | 7 |
| 等待并请求 GC 后 | 138628 | 20316824 | 10562208 | 0 |

结束 PSS 比起始高约 1.2 MiB，Java/Native 已用量回落，未观察到这组操作下持续增长或遗留面板引用。中途引用会随视图/消息队列回收而消失。数据来自带 instrumentation 的进程，并非正式版独立运行内存基准；不能把暂时增长直接判定为泄漏。

千条剪贴板/常用语列表 20 次开关仍通过虚拟化测试，PSS 波动而非单调增加；这组测试没有最终等待 GC 的独立基准，不能据此量化长期泄漏。
