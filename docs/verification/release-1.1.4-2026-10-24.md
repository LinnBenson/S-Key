# 1.1.4 发布检查 · 2026-10-24

版本：1.1.4（110）。

## 功能与边界

- 中文输入偏好新增“输入框预览”，默认关闭。开启时使用系统 composing 区域展示未确认的五笔、混输或拼音内容；选词后替换为正式文字。
- AI 和翻译原文框使用本地预编辑连接。预览更新抑制原文变更监听，未确认编码不写入请求草稿；确认候选后统一更新原文。
- 关闭预览时，联想加载和结果阶段保留编码行高度；开启时隐藏键盘内编码行。
- 密码框禁用预览。关闭开关、隐藏键盘、切换输入框及清空组合时释放预编辑连接和文本引用。
- 外部移动选区时结束预编辑所有权，不在新光标位置执行删除；宿主如何呈现 composing 样式取决于应用实现。

## 验证

- JVM 单元测试 256 项、Python 测试 12 项通过。
- 静态隐私检查、差异空白检查通过。原“仅键盘内预编辑”的静态规则改为仅允许专用 EditorPreview 使用 composing API，并要求显式开关和密码框检查。
- root BlueStacks 隔离包设备回归 10 项通过：普通输入框预览、退格与选词替换、关闭与密码框、连续组码与隐藏清理、AI/翻译原文与草稿隔离、联想编码占位、原文选区替换、退格、工具切换、五笔和拼音联想。
- 其中原有面板隐私/内存用例运行 60 次开关循环，完成后 retainedViews=0；Java 已用内存由约 30.7 MB 回落至约 30.5 MB。该结果不代表全部宿主或长期运行场景均无泄漏。
- arm64-v8a、x86_64、universal 正式包完成版本、签名及词库资源校验。

设备测试未覆盖所有第三方输入框。未使用真实 API 密钥在线调用；预览开启后宿主应用会收到未确认编码，默认关闭时保持键盘内预览。
