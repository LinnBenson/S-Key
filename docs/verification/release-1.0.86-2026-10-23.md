# 1.0.86 发布前功能、隐私与内存复查

日期：2026-10-23。版本：1.0.86 / versionCode 93。测试使用独立应用 `io.secure.keyboard.audit`，正式应用的数据未用于测试。设备为 Android 模拟器；以下内存数值包含测试框架开销，不能等同于真实手机上的空闲输入法内存。

## 本次修复与功能

- 快捷表情配置损坏时，键盘跳过该可选配置继续正常查询候选；设置页显示错误，允许用户确认后恢复默认。原配置不会被静默覆盖。
- 编辑期间条目已被删除时，保存会拒绝过期编辑，不重新创建已删除条目。
- 纳入本轮先前完成的密码框表情隐私修复、最近表情独立异步保存、设置内容快照复用与离线模型校验取消。
- 纳入快捷表情管理与搜索、直接关键词触发、备份版本 3、内容清理范围说明、自定义 AI 提示词 20000 字符及匹配的总容量限制。
- 更新旧诊断夹具：数字符号页先回到字母页再切换语言；反射访问实际 KeyboardSession；异步虚拟列表等待数据并挂载当前根视图；搜索等待 Compose/无障碍状态更新。

## 隐私检查

60 次内容面板开关和 60 次助手/工具切换后，候选查询、连接引用、编辑器、预览和助手临时结果按断言清理。合成输入标记未出现在测试私有文件或设置中。密码框表情不写历史；清理前排队的历史写入被代际标记拒绝。

应用仍按用户配置保存剪贴板、自定义内容和最近表情；备份是用户主动导出的明文。联网功能会把相应文字或录音发送到配置接口，AI 会话沿用服务端 `store: true`，本机清除不能删除提供商保留的数据。系统备份关闭、明文 HTTP 禁用、API 配置由 Keystore 加密的策略未变。未发现新增输入/录音日志或统计上传代码。

## 内存与性能证据

| 场景 | 结果 |
| --- | --- |
| 60 次内容面板开关 | 线程 31→31，文件句柄 86→86；PSS 149.9→155.3 MiB |
| 60 次助手/工具切换 | 线程 31→31，文件句柄 86→86；PSS 152.3→166.5 MiB |
| 慢输入框阻塞期间提交 1000 次刷新 | 最多 1 个执行中任务和 1 个待处理任务；结束后均为 0，过期输入框读取次数为 0 |
| 万条逻辑候选关闭 | 隐藏后展示模型释放断言通过 |
| 剪贴板/常用语列表 | 以虚拟列表提供全部逻辑条目，仅可见行持有完整文本；隐藏并清除后的引用诊断通过 |
| 五轮中英文各一万条导入、加载、清空 | 最后一轮自然等待 60 秒后，10 个旧快照均不可达；PSS 约 84.5 MiB，Java 使用约 3.8 MiB |
| 三轮原生识别器创建、公开音频解码、释放 | 无逐轮持续增长；首次峰值约 582.4 MiB，三轮释放后 10 秒 PSS 分别约 385.6 / 245.1 / 250.3 MiB |
| 五次启动计时 | 模型校验 39/12/12/12/12 ms；识别器创建 364/347/344/350/341 ms；stream 创建均不足 1 ms |

原生识别的首次峰值和分配器残留仍较高；这不是“零泄漏”的证明。此轮没有改成长期缓存识别器，以免延长原生内存驻留、削弱模型校验或引入跨录音状态污染。低内存实体设备和不同厂商音频驱动仍需专项实测。强制 GC 的连接可回收性诊断与上述自然回收数据分开记录：诊断任务生产方法返回后，10 个旧输入框连接全部可回收；方法返回前的 1 个暂存引用随后消失，说明测量会受诊断范围与回收时机影响；未单独定位该临时引用的 GC root，不能将它判定为应用泄漏。
