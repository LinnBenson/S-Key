# 2026-10-23 全盘检查与模拟器回归

基线：v1.0.83（versionCode 90，b6b04f1）。以下为发布前检查记录，修正随 v1.0.84（versionCode 91）发布。
环境：BlueStacks Air，Android 13，arm64。不是 Android 17 / One UI 真机验证。

## 本次修正

- 网络 JSON 解析前增加 64 层结构上限、长度及结构检查。此前虽限制响应大小，仍可能被很小但深度极高的 JSON 触发平台递归解析栈溢出。AI 流式响应、语音识别、语音翻译、普通翻译和模型列表均接入检查；不输出响应原文。新增 JVM 边界测试与 Android 深层响应失败后正常请求回归。
- 清除 23 个无调用图标及 1 项旧颜色。核对 Kotlin、XML、测试与资源查找方式，两个动态资源查找只访问 Android 系统资源。保留仍有调用的资源。
- 修正图标生成脚本：只生成实际使用的 Miuix 资源，并保留现有编辑、悬浮、返回上一项、显示等映射。在临时目录生成并比对，全部生产图标映射一致，资源均存在。
- 修正 3 个置顶剪贴板旧断言：条数限制约束非置顶历史，自动清理不能删除置顶内容。
- 快速输入和底行布局测试改用隔离目录、偏好与 Application；主线程断言错误转交测试线程，避免单项断言终止整个进程。
- 设置弹窗测试移除非必要 UiAutomation 截图，保留宽度、边距、按钮对齐断言。视觉截图可单独使用 adb 获取。

- JVM：266 项通过（包括 4 项新增网络 JSON 检查）。
- Python：42 项通过；隐私静态检查通过。
- Android：251 个去重后的现行回归/诊断用例执行通过。重复执行只计一次；已更名的旧失败断言不重复计入；缺模型的返回不算实际通过。
- Debug、AndroidTest、Release 构建成功；Lint 0 error、59 warning（检查前 96 warning）。仍有弃用 API、矢量路径、绘制分配及 Cursor 静态提示；所核对 Cursor 位于 use/finally 管理中，未因此删掉真实关闭逻辑。
- 本地 arm64 非调试包签名校验通过，安装到模拟器；确认包标记不含 DEBUGGABLE。实际打开试打框，逐键点击 nihao，首选显示“你好”，点击空格后上屏“你好”并显示后续联想。该安装验证完成于版本号提升之前。

## 内存、隐私与文件

60 次内容面板循环：PSS 从 119217 KiB 至 121652 KiB，采样峰值 125069 KiB；文件句柄始终 85，线程稳定至 24。60 次 AI 工具循环：PSS 从 118467 KiB 至 121704 KiB，峰值 126910 KiB；句柄始终 85，线程从 29 回到 24。未强制 GC；未观察到持续单调增长。这是带测试框架的进程，不能等同正式键盘的独立常驻内存或所有机型的峰值。

测试输入哨兵未写入隔离私有内容和设置。普通输入离线，密码框限制候选、剪贴板和在线助手；API 配置使用 Keystore 加密，备份排除密钥、剪贴板与续聊状态。在线功能仅测试替身响应，没有调用真实付费接口。录音 PCM 仅内存持有，取消/结束清理；语音请求具备总超时且不自动重传。

本轮存储诊断：未完成模型导入目录 0，content.tmp 不存在，cache 文件 0。活跃词库目录、编译索引和用户草稿不是垃圾，未为缩减体积删除。测试诊断仅数字，不上传原始日志或用户数据。

## 未完成与仍需注意

1. 真实麦克风采集诊断失败：MIC 和 VOICE_RECOGNITION 两个源均返回 0 个样本。未把该失败当成应用语音正常；模拟器无法证明实际拾音效果。
2. 未安装指定离线模型，12 次 native recognizer 测试明确跳过；不计入通过数。
3. 一项底行真实屏幕像素测试在 UiAutomation 截图时触发 BlueStacks lib_renderControl_enc / gralloc 驱动崩溃，未完成。其余不依赖该通道的布局断言通过。设置弹窗移除非必要截图后已复测通过。
4. 普通翻译和模型列表仍用 HttpsURLConnection 的连接/读取超时，缺少像语音请求一样的整个请求硬期限；极慢分块响应仍可能长时间占用工作线程。建议后续统一传输层并加入写入/总超时回归，本轮未改其传输机制。
5. 备份恢复对可捕获 I/O 异常有回滚，但多份偏好与内容文件间不具备进程被杀时的完整事务原子性。不能把异常回滚测试当成断电恢复保证。
6. AI 续聊使用 store:true；清空本机会话不等于删除服务端记录。现有 README 已说明。普通本机剪贴板/词库是应用私有文件，并非全部加密。
7. 首轮旧快速输入和底行测试尚未隔离时，写过模拟器的英文补全、四码上屏、振动、长按开关，以及当前布局/主题；测试进程中断可能未执行恢复。本轮已改为隔离测试，未猜测回填未知的原值；没有清除用户内容或 API 配置。

本报告是本轮代码检查与所列测试的结果，不是全部功能、所有设备和长期使用均无缺陷的保证。
