主要测试基础设施差异：

- 旧 UI fixture 反射已删除的 SettingsActivity.content/config、VoiceSetupActivity.importObserver/onActivityResult；崩溃栈来自测试注入。

- 剪贴板默认上限 10、最大 100；部分旧用例期待 12/13/1000 条。
- 加密拆分后，仅写剪贴板/常用语不会创建 content.json；旧测试直接读取该文件导致 ENOENT。
- 超过字符容量上限的旧词库压力测试被拒绝；该拒绝符合当前容量策略。
- 新安装没有 Google API 密钥；真实 Google 翻译请求未完成验证。
- JUnit3 将 Kotlin 生成的私有 test... 辅助方法误判为测试，产生 warning 方法失败。

以上分类不覆盖全部失败；剩余交互失败需要逐项复验，不能统称为测试误报。

## 已确认性能问题

P2：输入框预览与自动插入空格同时开启时，`InputController.kt` 的预编辑提交分支在 UI 主线程调用 getTextBeforeCursor/getTextAfterCursor。专项 InputConnection 探针记录到 2 次主线程读取，预期 0 次。慢宿主的同步 IPC 会阻塞键盘。两个选项目前均默认开启。本轮仅确认并记录，未修改生产实现。

## 安全和隐私

- EncryptedContentRegressionTest 五项通过：加密迁移、复制不重写词库、篡改拒绝、迁移中断保留旧数据、新默认值和密钥并发（一个方法可包含多项断言）。
- AiWritingTest 18 项通过，包含 SSE 封装开销不累计为输出、单事件/输出边界、截断和取消。
- Manifest 禁止系统备份及明文网络；IME 导出受 BIND_INPUT_METHOD 权限保护，设置页面不导出。
- 剪贴板、常用语、最近表情分别使用 AES-GCM 文件，位于不参与备份的目录；API 密钥和对话存储也使用既有加密机制。
- 自定义词库、AI 预设与主动导出备份仍包含明文；不应描述为所有数据均加密。
- 这是源码审查与本地回归，不是完整渗透测试或外部服务安全审计；未使用私人云端凭据。

词库单次校准：双语词库清空后 10 秒 PSS 为 58,209 KiB，低于导入前 88,926 KiB；五次完整导入/加载/清空及独立可回收性测试均通过。探针文件按用例覆盖，所以数值导出不包含每个历史用例的完整时间线。

一万候选遍历：初始 PSS 113,311 KiB，遍历后 221,227 KiB；清空 60 秒后仍为 214,492 KiB。逻辑行和附着视图均为 0，但仅凭这组自然回落不能区分堆高水位、延迟 GC 与泄漏；另做独立强制 GC 归因，不与自然回落混写。

独立归因复验通过：同样先等待 60 秒自然回落，PSS 为 220,526 KiB，原生已分配 88,273,136 B；随后单独请求 GC，10,000 个旧候选 TextView 弱引用均变为不可达，原生已分配降至约 14,085,040 B，后续采样 PSS 为 146,314 KiB。说明本次高水位至少明显包含延迟回收，未发现这批候选视图的强引用泄漏；不应在产品中加入强制 GC 作为修复，也不能将此推论扩大到所有内存对象。长列表自然回落速度仍可优化。

## 最终结论和安装状态

本轮审计不通过完整验收：存在一个可稳定复现的主线程性能缺陷，旧测试基础设施有多处失效，部分交互和真实录音路径仍未确认。加密/迁移/并发和 SSE 专项通过；剪贴板复制没有复现词库大小成比例的分配，重复面板/助手/原生静音循环没有线程或 FD 持续增长，候选旧视图可回收。

没有修改生产 APK 来掩盖失败，已确认的主线程问题仍待修复。审计结束后移除测试 APK，卸载被测试应用以清除合成数据和公开模型，再安装同一 ARM64 签名正式包，并启用、选择 S Key 输入法。新安装需要重新授予麦克风权限和导入模型。
