## 隐私结论与边界

普通打字未发现自动网络上传或持久保存完整输入历史的路径。AI、翻译和在线语音具有明确网络入口；密码输入由独立策略限制，候选和异步请求检查当前编辑器/版本。密钥加密保存，在线请求禁止自动重定向，录音不落盘。

剪贴板历史仍按用户配置保存在私有目录，普通内容不加密；系统允许时隐藏键盘的监听也可收到复制事件。AI 续聊使用服务端存储，本地清理不会删除服务商数据。这些行为已在 README 明确，不将“本地输入”等同于整个应用不联网。

## 未覆盖与后续优化

- 设备验证为 root BlueStacks arm64 模拟器，不能代表所有实体设备、折叠屏和宿主编辑器；触摸时间不是硬件端到端延迟。
- AI 与在线语音传输使用测试替身验证协议、取消和隐私边界，没有用真实密钥发送私人文字或录音。
- 本轮未做实体麦克风识别质量、所有网络服务可用性或长时间电量测试。
- 内存验证区分逻辑引用释放与 GC 可回收性；GC 辅助检查不等同于自然 PSS 曲线，也不能证明所有场景没有泄漏。
- 后续可继续处理无障碍提示和绘制/布局缓存初始化；大词库编译仍需要时间，不能用查询耗时代表编译耗时。
