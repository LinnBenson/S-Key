# 1.1.3 发布检查 · 2026-10-24

版本：1.1.3（109）。

## 修复与功能

- 五笔和混输候选上屏后使用本地拼音词库联想，支持连续点选及四码自动上屏。候选代次、连接身份和词库版本继续校验。
- 英文释义保留正常大小写、标点和长解释。按拼音的专名标记区分普通读音与专名读音；组内保留源词义顺序，不再按英文首字符排序。
- 分号只在括号外分隔词义。仅含中文引用的跳转才按重定向处理，保留 see you next time 等普通英文。
- 联想 SQLite 查询接入 CancellationSignal；新候选查询、清空组合和退出时取消旧信号。每次后缀查询开始前也检查取消。
- 学习词典打开成功后删除未被当前进程连接使用的旧哈希数据库；不删除其他文件或临时解压文件。
- 更新 README 和 APK 内 NOTICE 的转换规则说明。

## 边界
