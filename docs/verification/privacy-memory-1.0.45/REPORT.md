# S Key 1.0.45：流式、隐私和内存专项检查

日期：2026-10-18。版本：1.0.45（52）。环境：BlueStacks emulator-5554，debug 构建。

## 修复

- 流式解析兼容 LF、CRLF、CR，以及最后一个事件没有空行的响应。
- 连接提前结束必须报告中断；只有明确完成标记才作为完整结果。长度截断、工具调用等非正常完成原因不进入成功流程。
- 服务端错误和格式错误使用本地通用提示，不将服务端错误正文展示给用户。
- 保留响应总量与结果长度限制、取消检查和预览节流，增加流式读取耗时检查。读取超时仍为 60 秒，因此 180 秒检查不是独立的硬截止计时器。
- 修正手势测试：开启自动空格后提交是异步的，测试需要等待完成再判断，不能在松手的同一个主线程回调中立即断言。

## 验证

- debug 与 androidTest 构建通过；204 项 JVM 单元测试通过。
- 8 项 AiWriting 设备测试通过：请求构建与取消、换行格式、中文及表情、结尾事件、完成及 usage 事件、截断与不支持的结束原因、取消、响应大小限制。
- 3 项面板设备测试通过：60 次内存循环和隐私、空原文退格退出、退出后取消排队的敏感请求。
- 1 项空格早期滑动测试通过。最初的测试进程崩溃来自过早的主线程断言，修正测试等待后单独复测通过。
- tests/privacy_audit.py 通过。生产源码未发现输入内容日志输出；日志中的合成隐私标记出现次数为 0。
- 本轮没有调用用户真实 AI 或翻译接口；流式解析通过模拟响应验证。

## 隐私与范围

网络入口为翻译、AI 生成、模型列表及 AI 语音；自定义 HTTPS 地址决定实际接收方。普通输入离线处理。API 配置加密、备份禁用；手动保存的本机内容并非全部加密。

本次没有导出包含用户数据的堆转储，也没有清空用户数据。已安装 debug 更新。未发布 GitHub。

本轮属于定向回归与静态检查，不等于完整功能认证。真实网络服务的长连接行为、长时间压力运行和离线语音原生模型的内存仍需专门实测；不能据此保证不存在任何隐私风险或内存泄漏。
