## 隐私边界与未覆盖项
剪贴板、常用语和手动保存的提示词等仍为应用私有目录明文；普通剪贴板文字可能包含用户复制的敏感信息，不承诺自动识别所有密钥。AI 原文/结果不自动持久化，录音仍为内存缓冲。

本次没有真实付费 API、恶意/异常 SSE 服务端专项测试、真实麦克风长时运行、完整抓包、heap dump 或数小时压力测试；8 项设备测试并非所有功能的全量回归。长按整卡手势与预览弹窗未做完整触摸自动化验证。
