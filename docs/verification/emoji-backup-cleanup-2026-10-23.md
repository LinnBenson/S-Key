# 快捷表情、备份与内容清理验证（2026-10-23）

## 范围

- 偏好设置 → 内置设置 → 快捷 emoji 表情：列表展示表情与关键词，支持添加、编辑、删除，英文逗号分隔，自动去除关键词首尾空格及重复项。
- 默认沿用原有 110 条表情映射。完整覆盖列表独立保存在设置中，删除默认条目或删除全部条目不会被默认值补回。
- 中文候选词、英文候选词及直接输入的完整关键词均可触发表情。保留文字候选优先顺序，五笔原有自动提交路径不变。配置变更会使候选查询失效并刷新；词表按配置变化缓存，不按每个按键解析。
- 新备份版本为 3，包含中英文自定义词库、常用语（含置顶）、自定义 AI、主题颜色、主题 UI 设计、工具栏、自动闭合、符号键盘、字母长按符号、内置 AI 提示词、快捷表情和四个布局。
- 继续接受版本 1、2：版本 1 不改设置；版本 2 缺少新配置组时保留当前 UI 设计及快捷表情配置。空配置组和缺失配置组有不同含义，避免旧备份意外重置新增配置。
- 内容清理入口改名为“清除用户内容数据”。按用户更正，清除的是自定义 **AI**，不是自定义 UI；同时清除中英文自定义词库、常用语（含置顶）、剪贴板（含置顶）、最近表情及 AI 会话。保留内置词库、主题 UI 设计和其他设置。
- 备份不含内置词库文件、剪贴板、最近表情、会话、API 密钥或语音模型。备份是用户主动导出的明文 JSON。
