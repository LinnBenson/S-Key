# S Key 1.1.6 发布检查

版本：1.1.6（112）。

## 改动

- 原生输入框使用 `commitText` 直接替换当前 composing span，不再先删除编码再提交候选词。自动空格开启时，预览上屏不进入后台提交队列。
- AI／翻译原文框也直接替换预览编码。保留重入保护、光标回执识别、密码框限制及上屏成功后的英语释义查询。
- 文件选择器返回时，导入等待词库页面初始化或当前操作完成；通过 SavedStateHandle 保留导入类型。同名覆盖仍完整校验后发布源文件。

## 验证

- 256 项 JVM 单元测试通过。
- 12 项 Python 测试及静态隐私审计通过。
- 正式 ARM64 包在 root 模拟器上回归：后台线程阻塞时同步替换预览、无单独清空 composing 操作、退格与密码框、重复显示隐藏后的引用释放、AI／翻译原文框、初始化期间导入、六个词库校验覆盖与编译切换。
- 真实系统输入连接与离线 WebView 验证候选点击、空格、四码自动上屏及自动空格。
- 三种架构正式 APK 签名与词库资源检查通过；未增加网络请求、输入日志或用户文本持久化。

## 边界

设备回归覆盖本次使用的 Android 模拟器、标准 EditText 和 WebView；不代表穷尽所有第三方编辑器。自动空格开启时，需要同步读取编码旁的少量字符，编辑器本身的 IPC 响应仍可能影响耗时。内存检查覆盖引用释放与生命周期，不是长时间堆分析。
