# S Key 1.1.7 发布检查

版本：1.1.7（113）。

## 修复

系统文件选择器打开时，设置页会在后台隐藏 Compose 内容并释放敏感界面数据。原先由词库页面注册的文件选择回调也随之注销，导致选择文件后没有反应。

导入和导出现在由 Activity 注册回调，导入类型和待导出的文件 ID 保留在 SavedStateHandle。词库初始化未完成时，返回的操作等待初始化完成后执行。后台敏感界面清理保持启用。

另修复实际导出发现的扩展名问题：使用通用二进制 MIME 保留用户指定的原始文件名，避免系统将 TSV 名称追加为 `.tsv.txt`。

## 真实文件选择器验证

在 root 模拟器安装正式 ARM64 包，操作 Android DocumentsUI，而非只调用仓库方法：

- 新增 TSV 文件后返回应用，显示导入成功，编辑器可读到测试内容。
- 分别覆盖六个默认文件，逐个打开编辑器核对新内容。
- 导入词频无效的同名文件，显示具体行号错误；重新打开编辑器，原有效内容保留。
- 导出 TSV，保存名称没有追加 `.txt`，读取文件逐字节核对一致。
- 点击“编译并应用”，界面显示“编译成功，已应用新词库”。

测试使用合成词条；完成后恢复测试前的词库目录。1.1.6 未覆盖真实文件选择器的验证不足已在对应记录中更正。

## 自动回归与隐私检查

- 256 项 JVM 单元测试、12 项 Python 测试及静态隐私检查通过。
- 28 项设备测试通过：设置页按需加载与后台清理、Google 密钥只通过请求头传递、请求取消、英语释义迟到结果与数据库关闭、语音取消不落盘与捕获线程上限、预览直接替换、同名词库校验。
- 另外通过原生输入框与离线 WebView 的真实预览上屏，以及十次收起／弹出后的输入回归，共 31 项设备测试通过。
- 使用合成输入分别进行 60 次剪贴板／常用语面板切换、60 次 AI／翻译／工具切换、60 次 AI 面板销毁。检查普通输入和 AI 草稿没有进入文件或偏好设置，面板与编辑连接按生命周期释放。
- AI 面板测试完成并等待回收后，旧视图存活数为 0。PSS 从 92,808 KiB 到 90,864 KiB；Java 使用量从 6,260,368 到 5,255,600 字节；native 已分配量从 13,699,008 到 12,118,064 字节。本轮没有观察到随切换持续增长。
- 生产语音、翻译与 AI 路径未发现输入文本日志或录音文件写入。语音模型文件、只读词库和配置属于功能资源，不是输入历史。
- 保留用户明确要求的剪贴板、常用语、最近表情和 AI 续聊。AI 续聊允许服务端存储；本地仅保存加密续聊标识，不持久保存对话正文。

## 测试前提修正

反复显示隐藏的旧 UI 测试依赖键盘编码栏的取消按钮，没有隔离用户的“输入框预览”设置。开启预览时该按钮不存在，测试等待超时，失败截图还触发了 BlueStacks 图形映射组件故障，继而使 UiAutomation 断开。已修改该测试，显式关闭预览并在结束后恢复原值。修正后该项独立重跑通过。真实预览上屏另由原生输入框和 WebView 用例覆盖。

## 验证边界

这是指定模拟器上的源码审查和有限次数生命周期回归，不等于覆盖所有设备、第三方编辑器或长期运行情况。语音测试使用合成数据与替代传输，不采集麦克风录音，不验证云端保留策略。释放引用和关闭连接不代表 JVM 会立刻将所有内存归还操作系统。
