# 1.1.1 发布检查 · 2026-10-24

版本：1.1.1（107）。重点检查空格显示英语翻译的查询取消、输入框生命周期、资源释放和离线词典打包。

## 修复与清理

- 修复宿主重启输入框、保留原键盘视图时空格标签引用丢失，导致后续释义不显示的问题。
- 关闭开关立即撤销旧查询；快速关闭再开启不会沿用旧结果。重新开始输入视图也释放上一次查词状态。
- 每次查词取消上一项任务和 CancellationSignal，移除排队任务及旧计时。工作线程和主线程回调都检查查询代次；关闭时移除回调、清空显示闭包，数据库在所属线程退出前关闭。
- 首次解压流、数据库游标均使用作用域关闭；取消解压会删除临时文件。不开启功能时不创建词典控制器、数据库连接或工作线程。
- 修复 Android 打包工具自动解压并重命名 `.gz` 的问题，压缩索引使用 `.bin` 资源名。构建清理旧生成文件，APK 仅允许四个规定的学习资源，并逐字节核验。
- 清理两项依赖过期候选数量的测试假设，改用当前默认五笔词库的完整分页数据验证。
- 开关名称改为“空格显示英语翻译”，移除副标题；AI 原文 / 结果区域与翻译区域统一高度。

## 资源与响应

- 连续 20 次打开、查询和关闭后，词典文件描述符和工作线程数量回到循环前的数量；等待线程终止后检查，不依赖 GC。
- 模拟器上已打开词典的 100 次精确查询合计约 2.61 ms。此数字不包含首次解压、任务调度和界面刷新，不代表端到端延迟。
- 派生索引包含 102,174 个简繁体查询键，压缩数据 1,279,501 字节，解压数据库 2,691,072 字节。APK 不包含完整原始词典快照。
- arm64-v8a APK 为 57,768,134 字节；相比接入前同架构本地基线的 56,477,603 字节，增加 1,290,531 字节（约 1.23 MiB）。

## 隐私与验证边界

查询只使用本地只读词典，不增加网络请求，不保存输入文本或查词历史；密码框和 AI / 翻译草稿不触发查词。磁盘上的只读索引可供下次查询复用，关闭连接不等于删除该文件。

关闭资源的检查覆盖本轮执行路径，不能证明所有实体设备和宿主应用组合都无泄漏。未进行长时间整机堆分析；lint 仍有 52 条无障碍、布局和 API 等既有警告。本轮未使用真实 API 密钥进行在线 AI 调用。
