3. MODIFICATIONS AND REPRODUCTION

This is a modified selection, not an unmodified upstream word list. Offline
Keyboard generated it on 2026-10-11 with these deterministic steps:

- Read SCOWL final/{english,american,british,british_z}-words.{10,20,35,40,50,55,60}.
- Keep only existing lowercase ASCII words of 2 through 40 letters; do not
  import upper/proper-name lists, abbreviations, contractions, possessives,
  punctuation, digits, multiword phrases, or special jargon lists.
- Explicitly admit the seven weekday names and twelve month names, which are
  ordinary keyboard vocabulary but capitalized in SCOWL. This does not admit
  personal-name lists or change/boost any frequency count.
- Intersect that spelling set with FrequencyWords' 2018 English top-50k list.
- For duplicate spellings keep the highest existing occurrence count.
- Rank by occurrence count descending, then ASCII spelling ascending.
- Keep the first 25,000 words. Store spelling and the unchanged count as TSV.

SCOWL allowed spellings: 79,643. FrequencyWords intersection: 31,182.
The data is not censored; normal dictionary words and colloquial language may
appear. Some words also have uses as names. It is not an exhaustive dictionary,
spelling-correction system, or a claim about present-day population frequencies.

The source distribution includes the pinned original TSV, conversion script and
SHA-256 manifest under third_party/open_dictionaries/. The Android application
queries only the active local SQLite dictionary. It does not download dictionaries
or learn frequencies from user input.
