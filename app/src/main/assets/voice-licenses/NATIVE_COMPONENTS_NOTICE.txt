Native voice components distributed with S-Key

The pinned upstream sherpa-onnx 1.13.8 AAR has SHA-256:
633c24321e06b1fe79feafa03ea16cbc0f8a286641e2da3559bac91bdb13bd96
https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.8

S-Key uses streaming speech recognition only. However, the distributed
libsherpa-onnx-jni.so also contains upstream offline TTS and Piper/eSpeak NG
code. Not invoking TTS does not remove that code or its license obligations.
Excluding the separate C/C++ API shared libraries does not remove it from JNI.
The original S-Key Apache-2.0 license does not relicense these components.
