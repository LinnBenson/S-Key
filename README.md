# S Key

面向 Android 的五笔键盘：以本地输入为基础，将翻译、AI 文字处理和语音输入放进键盘。

[下载最新版](https://github.com/LinnBenson/S-Key/releases/latest) · [版本记录](https://github.com/LinnBenson/S-Key/releases) · [反馈问题](https://github.com/LinnBenson/S-Key/issues)

## 功能

- **中文与英文输入**：五笔 86 与拼音混输、英文当前词补全、候选展开、中文和英文自定义词库。保留原版混输方式，不提供独立拼音或纯五笔模式。
- **键盘工具**：剪贴板、常用语、表情、快捷编辑，以及可配置的工具栏。
- **布局调整**：横竖屏、折叠屏、悬浮拖动与缩放、分离键盘和高度调整。
- **主题与外观**：Miuix 设置界面；黑白默认主题、手动切换、跟随系统、自定义配色、调色盘和完整键盘预览。白色主题默认强调色及首选候选颜色为 `#007AFF`。
- **翻译**：使用自行配置的 Google 翻译 API，支持语言选择、交换及记忆；进入时可读取选中文本，预览译文后插入。原文使用真实输入框，支持光标、选区编辑、英文补全和语音输入。面板显示在工具栏上方，展开时增加临时高度，保留按键大小。
- **AI 助手**：使用自行配置的 Grok API，提供润色、扩写、语气调整、翻译和自定义指令。默认先预览结果，再插入或替换选中文本；支持流式输出、继续修改、重新生成和会话内结果切换。原文框支持语音输入。语气包括自然、正式、日常、礼貌、简洁、生气和粗鲁。
- **自定义 AI**：为提示词命名（名称最多 40 字符、提示词最多 2000 字符），在设置中统一排序、编辑、删除；键盘按名称选择并自动填充。记住上次使用的自定义 AI，无有效记录时使用列表第一项；选择面板按每行三个块展示，并用强调色标记当前项；自定义标签显示当前所选名称。
- **语音输入**：可选择本地普通话识别或 AI 语音识别。AI 语音直接上传录音，无需本地模型；识别后自动上屏、清除面板记录并继续聆听。英文键盘下开启“语音自动翻译”时，先通过已配置的 Google 翻译接口译成英文再上屏；关闭时使用识别内容并将中文转为简体。中文键盘的 AI 语音结果也在本地转为简体。聆听面板用主题色波形显示实际录音音量。

## 内置词库管理（当前开发改动）

“内置设置”分组还提供“内置 AI 提示词”：可编辑各类助手要求并恢复默认。自定义 AI 统一提示词默认留空，仅使用用户填写的自定义指令；填入后才附加统一要求，保存后下次生成生效。

偏好设置中，“输入与外观”下方新增“内置词库”。按五笔、拼音和英文分类显示原始词库文件，支持新建、导入、重命名、删除和导出；打开后直接编辑原始文本，支持全文搜索及分段保存。添加、修改、删除及恢复默认先保存为草稿，点击“一键编译并应用”成功后生效；失败继续使用旧版本。原有中英文自定义词库仍即时生效。

英文词库开发更新：保留 25,000 个高频词，增加 ESDB 官方英美扩展词 108,051 个，总计 133,051 个；来源与重建见 [英文词库说明](third_party/english/README.md)。

构建会自动生成默认来源目录与查询索引，需 Python 3。[词库设计与格式](docs/architecture/dictionaries.md) · [项目结构](docs/architecture/README.md) · [验证索引](docs/verification/README.md)。

## 安装与启用

1. 从 [Releases](https://github.com/LinnBenson/S-Key/releases/latest) 下载 APK。本版通用包支持 `arm64-v8a` 与 `x86_64`。
2. 安装后打开 S Key，按页面提示启用并切换输入法。
3. 在偏好设置中调整布局、主题和工具栏；语音功能需授予麦克风权限。

最低支持 **Android 8.0（API 26）**。当前开发版本为 **1.0.77**（versionCode 84），包名为 `io.secure.keyboard`。

### 升级与数据

- 从旧版 S Key 覆盖升级，需要包名和签名均一致。自 1.0.77 起使用新的发布签名，与 1.0.76 及此前 GitHub 发布包不兼容。旧签名用户须先备份需要保留的数据与配置，再卸载旧版并安装本版；卸载会清除应用本地数据。已安装相同新签名本地测试版的用户可直接覆盖升级。
- 之前的 S Key For AI 使用 `io.secure.keyboard.ai`，与本版属于两个应用，设置和本机内容不会自动迁移。
- 本版发布证书 SHA-256：`8b5e269f48c451cd392da655165d2df8f1cb8bc0682908d609218bfb80980363`。
- 发布附件提供 SHA-256 校验文件。

## 自动插入空格

在“输入方式 → 中文输入偏好”开启“自动插入空格”（默认关闭），普通文字输入会在中文与英文字母、数字的交界处补空格，例如 `中aa文` → `中 aa 文`。不会拆开英文单词和连续数字，也不会重复添加已有空格；密码、邮箱和网址类型的输入框不启用此处理。

## 配置翻译与 AI

进入 **偏好设置 → AI 设置**，填写自己的接口地址、API Key 和模型。

| 功能 | 默认接口 | 触发方式 |
| --- | --- | --- |
| Google 翻译 | `translation.googleapis.com/language/translate/v2` | 原文输入后短按回车 |
| Grok 文字处理 | `api.x.ai/v1/responses` | 原文框短按回车首次生成或续聊 |
| Grok 模型列表 | `api.x.ai/v1/models` | 点击获取可用模型 |
| AI 语音 | `api.x.ai/v1/stt` | 使用 AI 语音并提交识别 |

API 服务需要自行开通，服务可用性、费用和模型权限由对应提供商决定。地址支持自定义 HTTPS 接口；使用代理时，内容和密钥会发送到所配置的服务器。

“AI 设置 → 使用设置”中的“语音自动翻译”默认为开启。英文键盘使用 AI 语音且开关开启时，需同时配置语音接口和 Google 翻译密钥；关闭后上屏识别内容（中文在本地转为简体），不调用翻译。识别后自动检测原语言并翻译成英文；翻译失败或取消时不会将原语言直接上屏。中文键盘的 AI 语音识别结果在本地转为简体；本地语音保持原有行为。

每个自定义 AI 可设置低、中、高、最高推理强度，默认低；更高强度通常等待更久，模型须支持所选档位。修改强度会重置当前续聊。

**自定义提示词**在“AI 设置 → 使用设置 → 自定义 AI”中管理。键盘中的选择列表只负责选择，不提供删除操作。AI 面板原文标题右侧的清空按钮保留当前提示词；设置中的“清空全部用户内容”仍会删除保存的自定义 AI。

## 使用 AI 助手

1. 输入原文，或先选中文字再打开助手；也可长按原文标题粘贴剪贴板并自动生成。原文框支持光标、选区、候选词和语音输入。
2. 无有效会话时按回车，按当前 AI 类型和提示词首次生成。有有效会话时，标题显示“续聊 xxxx”（当前 ID 前 4 位），按回车只提交本次文字与最新响应 ID。生成中回车可停止。
3. 每轮完整成功后清空未再次编辑的原文，保存最新 ID 并刷新 12 小时有效期。生成时编辑的新草稿保留；普通失败保留输入方便重试。
4. 切换类型、语气、翻译语言、自定义 AI / 提示词 / 推理强度或接口配置会重置会话。每个自定义 AI 是独立类型。原文旁 ×、工具栏返回或空原文双击退格退出也重置；普通退出和重启保留加密会话。
5. 结果最多临时保留 8 版。左右切换仅用于查看和插入，不改变最新续聊 ID；退出 AI 助手后清空所有历史结果。打开及发送前检查有效期，不使用定时器。
6. 点击完成的结果或长按回车插入，长按结果复制。支持生成后自动上屏；不会清除生成期间输入的新草稿。


## 离线语音

在“语音输入”中选择离线语音，下载并解压指定普通话模型，再选择包含 `model.int8.onnx` 和 `tokens.txt` 的文件夹。应用会校验模型后导入，模型不随 APK 提供。

本地识别无需调用 AI API；选择 AI 语音则无需下载本地模型。模型来源与校验信息见 [语音依赖说明](third_party/VOICE_DEPENDENCIES.md)。

## 数据与联网说明

普通中文、英文输入在设备内处理。应用不自动学习完整输入历史，不内置广告、统计或崩溃上报 SDK。

- 剪贴板、常用语、自定义词库、最近表情和手动保存的自定义 AI 提示词保存在本机。清空全部用户内容会一并清除自定义 AI。
- 带系统敏感标记的剪贴板内容不采集；未带标记的普通复制内容仍可能进入本机历史，不保证自动识别所有敏感信息。
- API 配置使用 Android Keystore 加密保存；应用备份与设备迁移备份关闭。普通本机内容存放在应用私有目录，不承诺加密存储。
- 翻译及 AI 文字处理会将面板内容发送到配置的接口；AI 语音会上传录音；英文键盘下开启语音自动翻译时，转写文字还会发送给配置的 Google 翻译接口。本地语音不上传录音，应用不将录音保存为文件。
- AI 原文与结果不自动写入本机持久历史；续聊响应 ID 按下述规则加密保存。手动保存的命名提示词属于持久化配置，可由用户主动备份。
- AI 多轮续聊启用 Responses API 服务端存储（`store: true`）。[xAI 官方说明](https://docs.x.ai/developers/rest-api-reference/inference/responses)响应及输入保存 30 天；普通退出只清空本次结果历史；本机会话 ID 加密保留至最近一次成功后 12 小时。清空原文或切换类型会重置本机会话，但不会删除云端记录。自定义接口须支持 `/responses`，其留存规则以提供商为准；不兼容或 ID 失效时提示失败，不自动回退并重发上下文。
- “浏览器下载模型”会打开 GitHub 下载页，由外部浏览器联网。
- 已禁用 AndroidX Emoji 自动字体初始化器，避免它自动请求系统字体提供者。源码检查未发现广告、统计或隐私内容日志；不代表所有设备和系统组件均经过网络抓包验证。

以上来自源码、依赖与正式版清单检查，不是全场景抓包结论。输入到其他应用的文字由目标应用自行处理。

## 从源码构建

准备 JDK 17、Android SDK 35 与 Python 3。在项目根目录执行：

```bash
# 从仓库内的 XZ 文件还原字体，不联网
python3 scripts/restore_source_assets.py

# 下载并校验固定版本的 sherpa-onnx Android 依赖
python3 scripts/fetch_voice_dependency.py

# 将实际 Android SDK 路径写入 local.properties
printf 'sdk.dir=/your/path/to/Android/sdk\n' > local.properties

./gradlew assembleDebug
```

Gradle 首次构建需要下载依赖。输出位于 `app/build/outputs/apk/debug/`。`assembleRelease` 生成未签名 Release APK，发布时需要自行签名；仓库不包含发布私钥、密码或 API Key。

验证命令：

```bash
./gradlew testDebugUnitTest assembleDebugAndroidTest lintDebug
python3 tests/privacy_audit.py
```

设备测试需要连接 Android 设备或模拟器。[验证记录](TEST_RESULTS.md) 区分当前构建检查和历史功能回归，不能视为所有设备均已验证。

## 项目结构与第三方资源

- `app/src/main/java/`：输入法、设置、翻译、AI、语音和本地存储。
- `app/src/main/assets/`：词库、字体和许可证声明。
- `app/src/test/`、`app/src/androidTest/`：单元测试与设备测试。
- `third_party/`：第三方组件来源、图标及许可说明。
- `scripts/`：资源还原、依赖获取和资源生成脚本。

设置界面使用 Miuix；专用键盘图标由 Material Symbols 补充；本地语音基于 sherpa-onnx。各组件、词库和字体遵循各自许可，详见随资源保留的声明。本仓库没有为所有内容统一授予同一许可证，部分补充资源的再分发许可仍需单独核实。

### 统一备份与还原

在「偏好设置 → 内容清理」选择「备份数据」，将中文自定义词库、英文自定义词库、常用语和自定义 AI 保存为一个 JSON 文件。词库页面不再提供单独导入、导出入口。

选择「还原数据」并确认后，打开备份文件即可一次性替换这四类内容，保留条目顺序和常用语置顶状态；剪贴板、最近表情、主题、布局及 API 配置不受影响。还原会重置 AI 续聊状态。文件须通过格式、条目和容量校验后才写入，损坏文件不会部分覆盖原数据。

备份是用户主动导出的明文文件，不包含密钥或对话 ID，请妥善保存。
