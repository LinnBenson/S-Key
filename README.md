# S Key

S Key 是一款 Android 输入法，支持五笔 86、拼音和英文。内置词库，日常打字不需要联网。键盘布局、颜色、符号和常用内容都可以自己调整，也可以配置翻译、AI 助手和语音输入。

[下载安装](https://github.com/LinnBenson/S-Key/releases/latest) · [版本记录](https://github.com/LinnBenson/S-Key/releases) · [反馈问题](https://github.com/LinnBenson/S-Key/issues)

## 打字

**五笔 86** 支持前缀候选、四码自动上屏和上屏后联想。忘记编码时，可以开启五笔拼音混输入，用拼音找字。

**拼音** 支持连续输入、分段选词、组句和首字母候选。模糊拼音有 17 组规则，可以按需要单独开启。

**英文** 支持单词补全、大小写保留和空格选词。中文、英文的自动联想分别设置；关闭英文联想后，字母直接上屏，不再查询联想词库。

输入时还可以使用：

- 简体、繁体输出切换。
- 输入框预览：在当前应用中显示尚未确认的中文编码，选词后替换成文字，默认开启。
- 中文自动空格：在中文与字母、数字之间补空格，默认开启，密码、邮箱和网址框不应用。
- 空格键英文释义：中文词语上屏后，在空格键上短暂显示英文释义。使用本地词典，不联网，默认关闭。
- 字母长按符号、中英文符号页，以及可编辑的符号自动闭合规则。

## 键盘外观与布局

支持白色、黑色和跟随系统主题。按键、文字、候选栏、工具栏等颜色可以分别修改，设置页提供键盘预览。按键间距、边框宽度和圆角也可以调整。

外屏、内屏的横竖屏布局可以分别保存。可调整键盘高度、两侧和底部留白，也支持分离键盘、悬浮拖动与缩放。

工具栏可以调整顺序。按键震动强度可调。

## 剪贴板、常用语与表情

剪贴板支持置顶、删除和自动清理。默认保留 24 小时，未置顶记录最多 10 条；保留时间可设为 1–72 小时，数量可设为 1–100 条，也可以选择不保存历史或长期保留。置顶记录不自动清理。

最近 5 分钟复制的内容，可在下次打开键盘时提示一次，方便直接粘贴。这项提示可以关闭。

常用语适合保存经常重复输入的内容。表情支持分类浏览、最近使用和关键词搜索，快捷表情的关键词也可以编辑。快捷编辑面板提供光标移动、选择、复制和粘贴等操作。

## 自己管理词库

应用内置五笔、拼音和英文词库，可以直接使用，也可以编辑、导入和导出。每种输入方式都有基础词库和高优先级词库，方便补充人名、术语或自己的常用词。

在 **偏好设置 → 内置设置 → 内置词库** 中修改词库后，点击 **编译并应用** 才会更新输入候选。导入或编译失败时，继续保留原来的有效内容。

支持 `.tsv`、`.txt` 和受支持的 `.dict.yaml` 文件。工具面板中的中文、英文自定义词库则用于快捷词条，保存后即可使用，不需要编译。

格式和排序规则见[词库说明](docs/architecture/dictionaries.md)，默认数据来源见[词库来源与许可](third_party/open_dictionaries/README.md)。

## 翻译与 AI 助手

键盘内可以翻译文字，也可以对选中的内容或手动填写的原文进行润色、扩写、调整语气。自定义 AI 支持保存自己的指令，并为不同任务指定模型。

AI 助手支持流式显示和续聊，生成后可以将结果插入当前输入框。翻译默认使用 Google Cloud Translation；AI 文字接口默认使用 xAI / Grok，支持兼容 `/responses` 的接口。

这些功能需要自行填写服务地址、密钥和模型，应用不提供共享密钥或额度。使用时，相应文字会发送到配置的服务。AI 续聊使用服务端存储，清空本机会话不会删除服务器上的记录。

## 语音输入

可以选择离线语音或在线 AI 语音。

- **离线语音**：使用 sherpa-onnx 普通话模型，在设备上识别，不上传录音。模型需要单独下载，再从设置中导入。
- **在线 AI 语音**：将录音发送到配置的接口进行识别，需要网络和接口密钥。

英文键盘下可以开启语音自动翻译，识别结果会再发送到翻译接口。语音输入需要麦克风权限，录音不保存为本机文件。

离线模型的下载来源和导入要求见[语音模型说明](third_party/VOICE_DEPENDENCIES.md)。

## 数据保存

普通打字和词库查询在本地完成，不保存普通输入历史。应用没有内置广告、统计或崩溃上报 SDK。

剪贴板历史、常用语和最近表情分别加密保存在应用私有目录，密钥由 Android Keystore 管理。API 配置和续聊标识也加密保存。自定义词库和自定义 AI 提示词保存在私有目录，但不加密。

密码框不使用 AI、翻译、候选补全或剪贴板采集。系统标记为敏感的剪贴板内容不会收录；未标记的敏感文字无法自动全部识别。系统允许时，剪贴板监听可能在键盘隐藏后继续接收复制事件，可在设置中关闭历史保留。

应用关闭了系统备份。需要换设备时，可以在 **偏好设置 → 内容清理** 中手动备份自定义内容和界面配置，内置词库文件另行导出。手动备份是明文文件，不包含剪贴板历史、API 密钥或对话 ID，请自行保管。

## 安装

需要 Android 8.0 或更新版本。提供 `arm64-v8a`、`x86_64` 和通用 APK；不确定设备架构时可以选择通用版。

1. 从 [Releases](https://github.com/LinnBenson/S-Key/releases) 下载并安装 APK。
2. 打开 S Key，按首页提示启用输入法并切换到 S Key。
3. 在“输入方式”中选择五笔或拼音，通过首页试打框试用。

同签名版本可以覆盖升级。如果旧版本签名不同，需要先导出重要内容，再卸载安装；卸载会清除应用数据。

发布证书 SHA-256：

```text
8B:5E:26:9F:48:C4:51:CD:39:2D:A6:55:16:5D:2D:F8:F1:CB:8B:C0:68:29:08:D6:09:21:8B:FB:80:98:03:63
```

## 从源码构建

需要 JDK 17、Android SDK 35 和 Python 3。首次构建需要联网下载依赖。

```bash
python3 scripts/restore_source_assets.py
python3 scripts/fetch_voice_dependency.py
printf 'sdk.dir=/your/path/to/Android/sdk\n' > local.properties
./gradlew assembleDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/`。`assembleRelease` 生成未签名包，需要自行签名后安装。仓库不含发布私钥、密码、API 密钥或离线语音模型。

项目结构和实现说明见[开发文档](docs/architecture/README.md)。反馈问题时，请提供应用版本、设备型号、输入模式和复现步骤，并去除截图中的私人内容。
