# S Key

**面向 Android 的本地五笔 86、拼音和英文输入法。** 日常打字与词库查询在设备上完成；翻译、AI 助手和在线语音按需使用你配置的接口。

[下载最新版](https://github.com/LinnBenson/S-Key/releases/latest) · [版本记录](https://github.com/LinnBenson/S-Key/releases) · [反馈问题](https://github.com/LinnBenson/S-Key/issues) · [开发文档](docs/architecture/README.md)

## 安装与启用

| 项目 | 说明 |
| --- | --- |
| 当前版本 | **1.1.7** · versionCode **113** |
| 系统要求 | Android 8.0（API 26）及以上 |
| 包名 | `io.secure.keyboard` |
| 安装包 | `arm64-v8a`、`x86_64`、通用版 |

1. 从 Releases 下载适合设备的 APK；不确定架构时选择通用版。
2. 安装并打开 S Key，按首页提示启用输入法并切换到 S Key。
3. 点击首页试打框，进入“输入方式”选择五笔或拼音。

同签名版本可以覆盖升级。1.0.77 起使用当前发布签名；更早的旧签名版本需要先导出重要内容，再卸载安装。卸载会清除应用数据。旧的 `io.secure.keyboard.ai` 是独立应用，不会自动迁移数据。本版词库只使用当前目录与文件名，不迁移旧词库目录；已有文件可通过导入重新使用。

## 输入功能

| 功能 | 当前行为 |
| --- | --- |
| 五笔 86 | 支持完整编码、前缀候选、上屏后联想和四码自动上屏；自动上屏可独立关闭 |
| 五笔拼音混输入 | 在五笔模式下开启，拼音候选与五笔一起查询；输入模式仍显示“五笔” |
| 拼音 | 连续拼音、分段选词、组句、首字母候选及上下文联想 |
| 模糊拼音 | 独立二级设置页，17 组可选规则，按自己的发音习惯开启 |
| 英文 | 当前单词前缀补全、大小写保留；支持空格选择首选词 |
| 空格显示英语翻译 | 默认关闭；中文候选上屏后显示词典释义 8 秒，未收录时保留输入模式标签 |
| 简繁转换 | 默认简体，可切换繁体输出 |
| 输入框预览 | 默认关闭；开启后在当前应用输入框显示未确认中文编码，选词后替换为文字 |
| 自动插入空格 | 可选在中文与字母、数字之间补空格，密码、邮箱和网址框不应用 |
| 快捷表情 | 通过 emoji 或关键词搜索；可编辑关键词，支持候选词触发表情 |

“输入方式”只有 **五笔 / 拼音** 两个选项。选择五笔后，在中文输入偏好中显示“五笔四码自动上屏”和“五笔拼音混输入”开关。拼音模式不触发五笔四码自动上屏。拼音组句和模糊查询仍可能有歧义，可以分段选词或调整模糊规则。

开启“输入框预览”后，未确认的中文编码会作为系统预编辑内容传给当前应用；默认关闭，密码框不启用；AI／翻译面板的原文框同样支持预览，未确认编码不进入请求原文。

### 空格显示英语翻译

在 **输入方式 → 中文输入偏好 → 空格显示英语翻译** 开启，默认关闭。中文候选成功上屏后，空格键显示对应的英文释义，例如“苹果”显示 `apple`；8 秒后恢复“五笔”或“拼音”。空格键保持原来的输入功能，文字单行显示、左右留白，过长时以省略号结尾。

优先精确查询本次上屏的 2～4 字汉字词；未命中时才读取光标前最多 4 个字符，按结尾的 4、3、2 个汉字依次匹配，首次命中即显示，支持简繁体，也能识别分开输入的词。不会跨空格或标点拼词；全部未命中则不显示。英文输入、组码、移动光标、粘贴、常用语、语音、密码框、禁止个性化学习的输入框和 AI / 翻译草稿不触发查询。它是词典学习提示，不根据上下文判断词义，也不翻译长句。

新内容上屏或移动光标会取消旧查询和计时。切换输入框、隐藏键盘或关闭功能会清除提示并释放查询线程和数据库连接，迟到的结果不会重新显示。关闭时不加载词典、不创建查询线程；开启后首次查询会在本地解压约 2.57 MiB 的只读索引，文件可供下次使用，不保存查词历史；读取的短文本仅用于当前查询，用完即释放引用，不写入文件或日志。

词典来自 [CC-CEDICT 固定快照](third_party/cc_cedict/README.md)，派生数据遵循 CC BY-SA 4.0。此功能无需联网，与可编辑的输入候选词库独立。

## 键盘与工具

- **布局**：横竖屏、折叠屏配置、键盘高度、分离布局、悬浮拖动和缩放。
- **外观**：浅色、深色、跟随系统；自定义颜色、按键间距、边框与圆角并预览。
- **工具栏**：可调整工具顺序；左右保留边距，图标均匀分布。
- **符号**：中英文各两页符号键盘、字母长按符号、可编辑自动闭合规则。
- **内容工具**：剪贴板、常用语、表情、快捷编辑和自定义词库。
- **快捷粘贴**：最近 5 分钟复制的内容可在下次打开键盘时提示一次；支持关闭。
- **剪贴板历史**：可不保存、按小时清理或长期保留；置顶内容不自动清理。删除与系统剪贴板相同的文本时，同时清空系统剪贴板。

## 词库管理

入口：**偏好设置 → 内置设置 → 内置词库**。

### 默认六个文件

| 类型 | 基础词库 | 本地高优先级词库 | 默认基础词条数 |
| --- | --- | --- | ---: |
| 五笔 86 | `skey_wubi86.tsv` | `skey_wubi86_high.tsv` | 136,916 |
| 拼音 | `skey_pinyin.tsv` | `skey_pinyin_high.tsv` | 65,125 |
| 英文 | `skey_english.tsv` | `skey_english_high.tsv` | 25,000 |

三个高优先级文件默认只有注释，没有词条。六个默认文件**不能删除或重命名**，可以编辑、导出，以及通过导入同名文件覆盖内容。其他新增词库可以删除、重命名。

默认数据来自固定版本的 Rime 五笔、Rime 简体拼音及 FrequencyWords / SCOWL 英文词频数据。来源、转换过程、许可与 SHA-256 见[词库来源说明](third_party/open_dictionaries/README.md)。

### 编辑、导入与生效

1. 新建、编辑，或导入 `.tsv`、`.txt`、受支持的 `.dict.yaml` 文件。
2. 同名导入要求词库类型一致，**完整校验通过后才覆盖源文件**；校验失败保留原内容。
3. 保存后点击 **编译并应用**。编辑草稿不会直接改变正在使用的候选。
4. 编译成功切换到新快照并释放旧引擎与数据库连接；失败继续使用原生效词库。

校验包含 UTF-8 编码、字段数量、词条与编码、非负整数词频、文件和行长度限制。每个文件最多 64 MiB、每行最多 8192 字符，编译总词条最多 100 万。普通词库不能为空，高优先级模板允许为空。恢复默认也需要再次编译应用。

TSV 使用真正的制表符分隔；以下示例中各列之间为 Tab：

```tsv
你	wq	100
你好	ni hao	100
```

上面两行分别适用于五笔、拼音文件，不能混入同一类型词库。英文格式为小写单词和正整数词频：

```tsv
hello	100
```

完整编码匹配时，高优先级文件中的词条优先；同编码按文件顺序。普通候选按词频及稳定顺序排列，前缀补全不强制置顶。`skey_pinyin.tsv` 供混输与纯拼音共用；其他拼音词库，包括 `skey_pinyin_high.tsv`，只参与纯拼音。

工具中的中文、英文**自定义词库**是另一套快捷词条功能，保存后即时生效，不需要编译。详见[格式、排序与编译机制](docs/architecture/dictionaries.md)。

## AI、翻译与语音

| 功能 | 接口或引擎 | 数据处理位置 |
| --- | --- | --- |
| 翻译 | 默认 Google Cloud Translation，可配置 HTTPS 地址 | 将待翻译文字发送到配置的服务器 |
| AI 助手 | 默认 xAI / Grok，文字接口需兼容 `/responses` | 将原文、指令和续聊标识发送到配置的服务器 |
| AI 语音 | 默认 xAI / Grok 语音接口 | 上传录音识别文字 |
| 离线语音 | sherpa-onnx 普通话模型 | 本机识别，不上传录音 |

在线功能需要自行配置接口、密钥和模型。自定义服务器会收到相应内容和密钥，请选择你信任的服务。应用不提供共享密钥或免费额度。

每个内置 AI 类型和自定义 AI 可单独填写模型 ID，留空时使用 AI 设置中的默认模型。

键盘工具依次为 **润色 / 扩写 / 翻译 / 语气 / 自定义 AI**。语气标签显示“语气: 自然”等当前值；再次点击语气或自定义 AI，在三列卡片菜单中切换。自定义 AI 显示上次使用的名称，首次使用选择第一项，没有配置时隐藏；名称超过 5 个字符时显示前 4 个和“…”（菜单中保留完整名称）。

AI 翻译默认将中文译成美式英语，其他语言译成简体中文，可编辑提示词。

AI 助手支持润色、扩写、语气、翻译和自定义指令；可以读取选中文字或直接填写原文。回车生成或续聊，再按回车停止；完成后点击结果或长按回车插入，也可开启自动上屏。自定义 AI 提示词最多 20000 字符，内置提示词最多 12000 字符；自定义 AI 的统一提示词默认留空。切换助手类型、指令、模型或接口会重置续聊；最近一次成功后 12 小时失效。

AI 语音识别后自动上屏。英文键盘下可将识别结果自动翻译，需要配置翻译接口；最终输出遵循简繁设置。语音需要麦克风权限。

离线模型**不随 APK 提供**。下载解压后，在设置中选择包含 `model.int8.onnx` 与 `tokens.txt` 的目录，校验通过即可导入。见[模型来源和依赖](third_party/VOICE_DEPENDENCIES.md)。

## 数据与隐私

- **普通打字在本地完成**，不保存普通输入历史；没有内置广告、统计或崩溃上报 SDK。
- 密码框不使用 AI、翻译、候选补全或剪贴板采集，表情输入不记录最近历史。
- 剪贴板、常用语、主动点选的最近表情、自定义词库等存储在应用私有目录，普通内容未加密。系统标记为敏感的剪贴板内容不采集，但应用不能自动识别所有敏感文本。系统允许访问时，剪贴板监听可能在键盘隐藏后继续接收复制事件；可关闭历史保留。
- API 配置和续聊标识使用 Android Keystore 加密；系统备份与设备迁移备份关闭。网络接口仅接受 HTTPS，并禁止自动重定向。
- 翻译、AI 和在线语音由主动操作触发；启用语音自动翻译后，识别文本还会发送到翻译接口。录音不保存为本机文件。
- AI 多轮对话使用服务端存储（`store: true`）。清空本机会话**不会删除服务器记录**，服务端保留策略由接口提供方决定。本机不持久保存 AI 原文和结果历史。
- 下载模型会打开外部浏览器；上屏到其他应用的文字由目标应用处理。

### 备份与清理

“偏好设置 → 内容清理”支持备份自定义词库、常用语、自定义 AI，以及主题、布局、工具栏、符号、闭合规则、提示词、各类型模型 ID 和快捷表情配置。还原前显示范围并要求确认，完成后重置续聊。

备份为**明文**，不包含剪贴板、API 密钥或对话 ID；内置词库文件需要单独导出。“清除用户内容数据”清理自定义内容、剪贴板、最近表情及本机会话，保留内置词库和界面设置。

## 从源码构建

需要 **JDK 17、Android SDK 35、Python 3**。首次构建需要联网下载依赖。

```bash
python3 scripts/restore_source_assets.py
python3 scripts/fetch_voice_dependency.py
printf 'sdk.dir=/your/path/to/Android/sdk\n' > local.properties
./gradlew assembleDebug
```

Gradle 自动校验默认词库源文件并生成查询数据库。Debug APK 位于 `app/build/outputs/apk/debug/`。`assembleRelease` 生成未签名包，发布前需要自行签名。仓库不含发布私钥、密码、API Key 或离线语音模型。

```bash
# 单元测试、静态检查和设备测试包
./gradlew testDebugUnitTest lintDebug assembleDebugAndroidTest
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tests/privacy_audit.py

# 核验已签名 APK 的词库资源
python3 scripts/verify_dictionary_apk.py /path/to/app-release.apk
```

设备测试需要连接 Android 设备或模拟器。生产查询使用只读 SQLite 索引、分页候选和有界缓存，避免将整套词库构造成 Java 对象。完整测试不能保证所有设备、宿主应用和第三方接口都没有问题。
