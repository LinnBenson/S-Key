# S Key

Android 输入法，支持五笔、五笔拼音混输和全键盘拼音。日常输入在本地完成，也可以配置自己的接口，在键盘里使用翻译、AI 助手和语音识别。

[下载最新版](https://github.com/LinnBenson/S-Key/releases/latest) · [更新记录](https://github.com/LinnBenson/S-Key/releases) · [反馈问题](https://github.com/LinnBenson/S-Key/issues)

## 安装

支持 **Android 8.0 及以上**。当前版本 **1.0.86**（versionCode 93），包名 `io.secure.keyboard`。

从 Releases 下载 APK，安装后打开 S Key，按提示启用并切换输入法。通用安装包支持 `arm64-v8a` 和 `x86_64`；语音输入需要麦克风权限。

**升级提醒：** 1.0.77 起更换了发布签名。1.0.77 及同签名测试版可覆盖升级；1.0.76 及更早的旧签名版本需要先备份，再卸载安装。卸载会清除本地数据。旧的 S Key For AI（`io.secure.keyboard.ai`）是另一个应用，数据不会自动迁移。

## 输入与键盘

- **三种中文模式**：在“输入方式”中选择五笔、五笔拼音混输或拼音，也可以添加到工具栏切换。默认混输，五笔使用 86 编码。
- **拼音输入**：支持连续拼音组句、分段选词、上下文候选和首字母候选。纯拼音模式不会触发五笔四码自动上屏。目前的组句能力仍有改进空间。
- **英文输入**：提供单词补全，有候选时按空格选中首项。
- **简繁转换**：默认简体。切换为繁体后，上屏文字中的简体会转为繁体；工具栏可显示“简 / 繁”切换键。
- **符号设置**：中文、英文各有两页符号键盘，支持点击预览中的按键修改。字母长按符号也可分别设置。自动闭合规则可编辑输入符号、闭合符号和光标回移位数。
- **快捷粘贴**：5 分钟内复制的内容在下次打开键盘时显示一次，点击粘贴；输入或点击 × 后收起。超过 5 分钟自动收起；键盘已打开时复制的内容留到下次判断，可在“键盘操作”中关闭。
- **剪贴板保留**：可选不保存历史、按小时清理或长期保留。置顶内容不自动清理，快捷粘贴可独立使用。
- **快捷 emoji 表情**：可添加、编辑、删除表情与关键词，多个关键词用英文逗号分隔，支持搜索 emoji 或关键词；输入完整关键词或匹配候选词时显示表情。
- **常用工具**：剪贴板、常用语、表情和文字编辑工具，可调整工具栏顺序。删除剪贴板记录时，若它与系统当前剪贴板文本相同，会同时清空系统剪贴板。

布局支持横竖屏、折叠屏、悬浮拖动与缩放、分离键盘和高度调整。主题可选浅色、深色、跟随系统，也可自行配色并预览。

“输入方式”中的自动插入空格默认关闭。开启后，中文与字母、数字之间会补空格，例如 `中aa文` → `中 aa 文`；密码、邮箱和网址输入框不使用这项处理。

## 词库

在“偏好设置 → 内置设置 → 内置词库”中管理五笔、拼音和英文词库。可以查看和编辑原始文件，也可以新建、导入、重命名、删除、导出或恢复默认。

修改保存后，点击“编译并应用”才会生效。导入、保存和编译会检查格式；编译失败时继续使用上一版词库。中文、英文自定义词库保存后即时生效，不需要编译。

混输模式的拼音候选只使用 `pinyin_simp.dict.yaml`，其他拼音文件用于纯拼音模式。该文件不能删除或重命名，内容仍可编辑。默认还提供一份首字母候选词库。英文词库包含高频词和 ESDB 扩展词，共 133,051 个词。

[词库格式与编译说明](docs/architecture/dictionaries.md) · [英文词库来源](third_party/english/README.md)

## AI、翻译与语音

这些在线功能需要自己的 API Key。在“AI 设置”中填写接口地址、密钥和模型；使用自定义地址时，内容和密钥会发送到该服务器。

| 功能 | 默认服务 | 用途 |
| --- | --- | --- |
| 翻译 | Google 翻译 | 选择目标语言，预览后插入译文 |
| AI 助手 | xAI / Grok Responses API | 润色、扩写、调整语气、翻译或执行自定义指令 |
| AI 语音 | xAI / Grok 语音接口 | 上传录音并识别文字 |
| 离线语音 | sherpa-onnx | 使用本地普通话模型，不上传录音 |

AI 助手可以读取选中文字，也可直接输入原文。按回车生成或续聊，生成中再按回车可停止。完成后点击结果或长按回车插入，长按结果复制；也可开启自动上屏。

自定义 AI 可以保存名称、指令和推理强度，提示词支持最多 20000 字符。“内置 AI 提示词”中可以修改各类助手的提示词，并恢复默认。**自定义 AI 的统一提示词默认留空，不会附加普通 AI 的通用要求。**

切换助手类型、提示词或接口配置会重置续聊。普通退出可保留会话，最近一次成功后 12 小时失效；结果历史仅在当前面板临时保留。自定义文字接口需要兼容 `/responses`。

AI 语音识别后自动上屏。在英文键盘下，“语音自动翻译”默认开启，需要同时配置 Google 翻译；关闭后直接使用识别内容。识别内容中的中文会先转为简体，最终输出遵循简繁设置。

离线语音模型不随 APK 提供。下载并解压后，在设置中选择包含 `model.int8.onnx` 和 `tokens.txt` 的目录，校验通过即可导入。[模型来源与依赖说明](third_party/VOICE_DEPENDENCIES.md)

## 数据与隐私

普通中文、英文输入在设备内处理，不自动学习完整输入历史。应用没有内置广告、统计或崩溃上报 SDK。

- 剪贴板、常用语、自定义词库和保存的 AI 指令存放在应用私有目录，普通内容未加密。带系统敏感标记的剪贴板内容不采集，但无法自动识别所有敏感信息。
- API 配置和续聊标识使用 Android Keystore 加密保存。系统备份与设备迁移备份已关闭。
- 翻译和 AI 助手会把待处理文字发送到配置的接口；AI 语音会上传录音。语音自动翻译还会把识别文字发送到翻译接口。离线语音不上传录音，应用不把录音保存为文件。
- AI 多轮对话使用服务端存储（`store: true`）。清空或重置本机会话不会删除服务端记录，保留期限以接口提供商的规则为准。原文与结果不会自动保存为本机持久历史。
- 下载离线模型会打开外部浏览器。输入到其他应用的文字由目标应用自行处理。

在“偏好设置 → 内容清理”中可以备份自定义词库、常用语、自定义 AI，以及主题颜色、主题 UI 设计、四个布局配置、工具栏、符号键盘、自动闭合规则、字母长按符号、内置 AI 提示词和快捷表情配置。还原前会显示数据条数和设置变更范围，确认后替换，并重置续聊。旧版备份仍可导入：版本 1 只恢复四类内容；版本 2 保留备份中未包含的 UI 设计和快捷表情配置。剪贴板和 API 配置不包含在备份中，内置词库文件需单独导出。

“清除用户内容数据”会删除中英文自定义词库、常用语与剪贴板（均包含置顶）、最近表情、自定义 AI 和本机会话；保留内置词库、UI 设计及其他设置。密码框使用表情不记录最近历史。

备份文件是明文，不包含密钥和对话 ID，请妥善保管。源码检查和测试情况见[验证记录](docs/verification/README.md)，其中也列出了未覆盖的场景。

## 从源码构建

需要 JDK 17、Android SDK 35 和 Python 3。在仓库根目录执行：

```bash
# 还原仓库内压缩保存的字体
python3 scripts/restore_source_assets.py

# 下载并校验固定版本的语音依赖
python3 scripts/fetch_voice_dependency.py

# 填写本机 Android SDK 路径
printf 'sdk.dir=/your/path/to/Android/sdk\n' > local.properties

./gradlew assembleDebug
```

首次构建需要联网下载依赖，Debug APK 输出到 `app/build/outputs/apk/debug/`。`assembleRelease` 生成未签名 APK，发布前需要签名；仓库不含发布私钥、密码或 API Key。

常用检查命令：

```bash
./gradlew testDebugUnitTest assembleDebugAndroidTest lintDebug
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tests/privacy_audit.py
```

设备测试需要连接 Android 设备或模拟器。[项目结构](docs/architecture/README.md)中说明了各模块的职责。
