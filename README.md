# S Key

**五笔、拼音与英文输入，配上你习惯的键盘。**

S Key 是一款 Android 输入法，支持本地词库、可调整的键盘布局，以及键盘内的常用语、翻译、AI 助手和语音输入。日常打字与离线语音在设备上处理；需要在线服务时，可自行配置接口与模型。

## 开始使用

需要 **Android 8.0 或更新版本**。

1. 在 [Releases](https://github.com/LinnBenson/S-Key/releases) 下载适合设备的 APK。
2. 安装并打开 S Key，按首页提示启用输入法，再切换到 S Key。
3. 在首页试打框体验输入，在设置中选择五笔或拼音、调整布局和主题。

| 安装包 | 适用设备 |
| --- | --- |
| `arm64-v8a` | 常见的 64 位 ARM Android 手机和平板 |
| `x86_64` | 对应架构的设备或模拟器 |
| `universal` | 包含多种架构，体积较大；以具体版本提供的附件为准 |

同签名版本可以覆盖升级。若旧版本签名不同，请先导出重要内容，再卸载安装；卸载会清除应用数据。

## 输入与编辑

### 五笔、拼音、英文

- **五笔 86**：前缀候选、四码自动上屏、上屏后联想，支持五笔拼音混输入。
- **拼音**：连续输入、分段选词、组句与首字母候选，可按需开启模糊音规则。
- **英文**：单词补全、大小写切换和空格选词，可独立关闭英文联想。

支持简繁输出、输入框预览，以及中文与字母、数字之间自动补空格。符号页、字母长按符号和符号自动闭合规则均可调整。

快捷编辑面板提供光标移动、选区、全选、剪切、复制和粘贴。空格键英文释义使用本地词典，可在中文词语上屏后显示简短释义，默认关闭。

### 常用语、剪贴板与表情

**常用语**可以直接在键盘上方添加、编辑，支持候选输入、多行、光标选区和自动空格。点击保存后写入本机存储，未保存草稿在取消或结束输入时清理。列表支持置顶和删除。

**剪贴板历史**支持置顶、删除、数量限制和到期清理。默认保留 24 小时、最多 10 条未置顶记录，也可关闭历史保留或选择长期保留。置顶记录不自动过期。最近复制的内容还可通过一次性快捷粘贴提示插入。

**表情**支持分类、搜索、最近使用，以及可编辑的快捷关键词。

## 键盘外观与布局

浅色、深色或跟随系统，可分别设置按键、候选、文字和工具栏等颜色。按键间距、圆角、高度和震动强度也可调整。

外屏、内屏的横竖屏布局分别保存，支持分离键盘、悬浮拖动与缩放，以及两侧和底部留白。工具栏图标可以按使用习惯排序。

## 词库管理

内置五笔、拼音和英文词库，每种输入方式提供基础词库与高优先级词库，可用于补充人名、术语和常用词。

在 **偏好设置 → 内置设置 → 内置词库** 中编辑、导入或导出，修改后点击 **编译并应用** 更新候选。编译失败时保留原有有效词库。

支持 `.tsv`、`.txt`、受支持的 `.dict.yaml`，以及按 `wubi/`、`pinyin/`、`english/` 目录组织的 ZIP 词库包。工具面板中的中文、英文自定义词库可直接保存生效。

详见[词库格式与排序规则](docs/architecture/dictionaries.md)和[词库来源与许可](third_party/open_dictionaries/README.md)。

## 翻译与 AI 助手

在键盘内翻译文字、润色、扩写或调整语气。原文可以手动输入，也可以从当前选区带入；结果支持插入当前应用。AI 助手支持流式输出、会话历史和续聊。AI 和翻译面板中，单击回车换行，长按回车提交；AI 正在生成时，长按回车可停止生成。

- **内置 AI 提示词**：可编辑通用要求、任务与语气提示词，并为支持的条目分别指定 Grok、Gemini 和 OpenAI 模型。
- **自定义 AI**：保存自己的指令，配置模型、推理强度和会话有效期。
- **联网搜索与 X 搜索**：自定义 AI 可分别开启，默认关闭，需要服务和模型支持。

翻译使用 Google Cloud Translation。AI 文字和 AI 语音可分别选择 Grok、Gemini 或 OpenAI，并独立配置地址、密钥和模型。内置 AI 跟随默认 AI 提供商，自定义 AI 可跟随默认或单独指定；Gemini 和 OpenAI 会忽略 X 搜索。Gemini 对话和语音设置位于 Google 页签的翻译接口下方，使用原生 Interactions API；Grok 和 OpenAI 对话使用 `/responses`。语音接口用于录音转文字，录音只在内存中处理。需要自行填写服务配置，应用不提供共享密钥或服务额度。

使用在线功能时，相应文字、选定的附件或录音会发送到配置的服务。AI 续聊涉及服务端存储，清空本机会话不会删除服务端记录。

## 语音输入

| 模式 | 处理方式 | 使用前准备 |
| --- | --- | --- |
| 离线语音 | 使用 sherpa-onnx 普通话模型在设备上识别 | 下载并导入离线模型 |
| 在线 AI 语音 | 将录音发送到配置的识别接口 | 配置接口、密钥并连接网络 |

语音输入需要麦克风权限，录音不保存为本机音频文件。英文键盘下可开启语音自动翻译，此时识别文字还会发送到翻译接口。

模型下载来源与导入要求见[语音模型说明](third_party/VOICE_DEPENDENCIES.md)。

## 隐私与本机数据

普通打字和词库查询在本地完成，不保存普通输入历史。项目未集成广告、统计或崩溃上报 SDK。

| 数据 | 本机保存方式 |
| --- | --- |
| 剪贴板历史、常用语、最近表情 | 分别加密保存在应用私有目录 |
| API 配置、AI 续聊记录 | 加密保存，密钥由 Android Keystore 管理 |
| 自定义词库、自定义 AI 提示词 | 保存在应用私有目录，未加密 |
| 未保存的常用语草稿、语音录音 | 在内存中处理，不作为草稿文件或音频文件保存 |

AI 续聊记录包含续聊 ID、任务配置、时间和首条消息摘要。会话有效期可设为 **0～720 小时**，默认 4 小时，0 表示不保留。内置 AI 共用有效期，自定义 AI 可以独立设置。本地续聊最多保留 100 条，并受总大小预算限制。

到期记录会安排后台清理，并在启动或回到前台时补清理；系统休眠或强行停止可能延后删除。清理本机内容不会删除已导出的备份或服务端记录。

在 **备份与清理 → 隐私保护** 中可调整截屏保护。默认关闭；开启后保护敏感设置页、助手和内容面板，关闭时允许这些界面截屏。

密码输入框不使用 AI、翻译、候选补全或剪贴板采集。系统标记为敏感的剪贴板内容不会收录，但应用无法识别所有未标记的敏感文字。系统允许时，剪贴板监听可能在键盘隐藏后继续接收复制事件；可在设置中关闭历史保留。

## 备份与还原

在 **备份与清理** 中导出密码加密的 `.skeybackup` 文件，换设备时输入同一密码还原。验证成功后会显示预览，由你确认覆盖。

- **包含**：自定义内容、界面与输入配置，以及接口地址、API 密钥和模型配置等 AI 设置。
- **不包含**：剪贴板历史、AI 会话记录、内置词库文件和离线语音模型。

新备份会还原输入方式、语音方式、声音与振动、截屏保护等偏好，包括明确关闭的开关。旧备份未包含的偏好保持设备当前值。

应用关闭了 Android 系统备份，不支持旧版明文备份还原。请保管好备份文件与密码，忘记密码后无法还原。

## 从源码构建

准备 **JDK 17、Android SDK 35、Python 3**。首次构建需要联网获取依赖。

```bash
git clone https://github.com/LinnBenson/S-Key.git
cd S-Key

# 还原压缩字体，并获取经过哈希校验的语音依赖
python3 scripts/restore_source_assets.py
python3 scripts/fetch_voice_dependency.py

# 改为本机 Android SDK 路径
printf 'sdk.dir=/your/path/to/Android/sdk\n' > local.properties
./gradlew assembleDebug
```

若使用发布附件中的源码 ZIP，请先解压并进入项目目录，再执行资源还原与构建命令。

Debug APK 位于 `app/build/outputs/apk/debug/`。`assembleRelease` 生成未签名 APK，需要使用自己的密钥签名后安装。源码不包含发布私钥、密码、API 密钥或离线语音模型。
